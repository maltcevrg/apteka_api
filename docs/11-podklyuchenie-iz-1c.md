# Подключение из 1С 7.7

Как обращаться к API из 1С:Предприятие 7.7 через `WinHttp.WinHttpRequest.5.1`, почему запросы бывают медленными и как это исправить.

## 1. Шаблон запроса

```1c
//*******************************************
// Запрос к API бонусных карт.
// Метод   — "GET", "POST", "PUT", "DELETE"
// Путь    — например "/api/v1/bonus/balance/1234567890123"
// Тело    — строка JSON для POST/PUT, для GET — пустая строка
// Статус  — возвращает HTTP-код ответа (0 — до сервера не достучались)
// Возвращает текст ответа (JSON) или пустую строку
//
Функция глЗапросAPI(Метод, Путь, Тело, Статус) Экспорт
    Перем http, Ответ;
    Ответ = "";
    Статус = 0;

    Попытка
        http = СоздатьОбъект("WinHttp.WinHttpRequest.5.1");
        http.SetProxy(1);                            // прямое соединение, прокси не искать
        http.SetTimeouts(3000, 3000, 5000, 10000);   // resolve, connect, send, receive — мс

        http.open(Метод, глАдресAPI + Путь, 0);
        http.setRequestHeader("Accept", "application/json");
        http.setRequestHeader("Authorization", "Bearer " + глТокенAPI);

        Если (Метод = "POST") ИЛИ (Метод = "PUT") Тогда
            http.setRequestHeader("Content-Type", "application/json");
            http.setRequestHeader("Expect", "");     // не ждать 100-continue
            http.send(Тело);
        Иначе
            http.send();
        КонецЕсли;

        Статус = http.Status;
        Ответ = http.responseText();
    Исключение
        Сообщить("Ошибка обращения к API: " + ОписаниеОшибки(), "!");
    КонецПопытки;

    Возврат Ответ;
КонецФункции
```

Где `глАдресAPI = "https://ваш-домен"` и `глТокенAPI` — токен, полученный один раз (раздел 3). Оба лучше хранить в константах, а не в коде.

Примеры вызова:

```1c
// Баланс
Ответ = глЗапросAPI("GET", "/api/v1/bonus/balance/" + СокрЛП(ШтрихКод), "", Статус);

// Начисление
Тело = "{""short_code"":""" + ШтрихКод + """,""pharmacy_number"":" + НомерАптеки
     + ",""inn"":""" + ИНН + """,""document_date"":""" + Формат(ДатаЧека, "ДГГГГММДД")
     + """,""document_number"":""" + НомерЧека + """,""document_type"":""sale"",""amount"":" + Формат(Сумма, "Ч15.2") + "}";
Ответ = глЗапросAPI("POST", "/api/v1/bonus/increase", Тело, Статус);
```

Что означает `Статус`:

| Код | Что значит | Что делать кассе |
|:--|:--|:--|
| 200, 201, 204 | Выполнено | Разобрать ответ |
| 202 | Запрос правильный, но операцию сделать нельзя: карта не найдена, бонусов не хватает, отменять нечего | Показать кассиру `message` из ответа |
| 401 | Токен недействителен | Получить новый токен (раздел 3) |
| 422 | Ошибка в данных: нет поля, неверный формат, номер чека уже использован | Ошибка в коде кассы или повтор чека; смотреть `errors` в ответе |
| 0 | Нет связи: таймаут, DNS, TLS | Повторить позже, работать без бонусов |
| 500 | Ошибка на сервере | Сообщить администратору |

## 2. Что важно в этом шаблоне и почему

**`SetProxy(1)`.** Без этого WinHTTP при каждом запросе может искать прокси в сети (WPAD). Если прокси нет, поиск заканчивается по таймауту — 3–6 секунд на каждый запрос. Postman этого не делает, поэтому из Postman быстро, а из 1С медленно.

**`https://`, а не `http://`.** Если сервер перенаправляет HTTP на HTTPS, WinHTTP выполняет два запроса вместо одного, а токен первый раз уходит по сети открытым.

**Для GET — `send()` без тела** и без `Content-Type`. API тело в GET не читает.

**`Expect: ""`** для POST. Иначе WinHTTP может отправить заголовки и ждать от сервера разрешения `100 Continue`, прежде чем послать тело.

**Заголовок `Host` не ставить** — WinHTTP подставит сам из адреса.

**Таймауты.** Без `SetTimeouts` ожидание ответа по умолчанию 30 секунд. При проблемах с сетью касса зависнет на полминуты на каждом чеке. 10 секунд на ответ — с запасом: API отвечает за 20–50 мс.

**Попытка/Исключение.** При таймауте или ошибке TLS `send()` выбрасывает исключение. Без обработки обработка остановится с красным окном.

**Кириллица.** Строки в 1С 7.7 — в кодировке Windows-1251. Если в теле есть русские буквы (имя клиента при создании карты), либо перекодируйте тело в UTF-8 перед отправкой, либо укажите `Content-Type: application/json; charset=windows-1251`. Иначе байтовая длина не совпадёт с `Content-Length`, и сервер будет ждать недостающие байты до таймаута.

## 3. Токен

Токен получается один раз и действует год. **Не запрашивайте его перед каждым чеком** — это лишний запрос, который на сервере стоит дороже любой операции с картой.

```1c
Функция глПолучитьТокенAPI(ClientID, ClientSecret) Экспорт
    Перем http, Ответ, Поз;
    http = СоздатьОбъект("WinHttp.WinHttpRequest.5.1");
    http.SetProxy(1);
    http.SetTimeouts(3000, 3000, 5000, 10000);
    http.open("POST", глАдресAPI + "/oauth/token", 0);
    http.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
    http.setRequestHeader("Accept", "application/json");
    http.send("grant_type=client_credentials&client_id=" + ClientID + "&client_secret=" + ClientSecret);
    Ответ = http.responseText();
    // access_token — длинная строка без пробелов в кавычках
    Поз = Найти(Ответ, """access_token"":""");
    Если Поз = 0 Тогда
        Возврат "";
    КонецЕсли;
    Ответ = Сред(Ответ, Поз + 16);
    Возврат Лев(Ответ, Найти(Ответ, """") - 1);
КонецФункции
```

Сохраните результат в константу. Запрашивайте новый только когда API вернул `401`.

## 4. Почему первый запрос медленный

**Первый запрос после открытия 1С — 1–3 секунды, дальше быстро.** Это Windows: при первом HTTPS-соединении она резолвит имя, проверяет сертификат (скачивает списки отзыва с серверов удостоверяющего центра) и делает полное TLS-рукопожатие. Всё это кэшируется на часы. Один раз в начале смены — нормально, делать ничего не нужно.

**Первый запрос после 5–10 минут простоя — 3–4 секунды, и из Postman тоже.** Это сервер: хостинг завершает процесс PHP без нагрузки, и следующий запрос поднимает его заново. Лечится прогревом на сервере (cron или внешний монитор) — см. [02-installation.md](02-installation.md), раздел «Медленный первый запрос после простоя». Со стороны 1С делать ничего не нужно.

**Каждый запрос 5–6 секунд.** Почти наверняка нет `SetProxy(1)` — см. раздел 2.

**Каждый запрос около секунды.** TLS-рукопожатие на каждый вызов. WinHTTP в 1С 7.7 не держит соединение между разными объектами. Можно создавать `WinHttpRequest` один раз на сеанс (в глобальном модуле) и переиспользовать — тогда соединение сохраняется.

## 5. Если HTTPS не работает

Ошибка вроде «безопасный канал», «secure channel», «SEC_E_ILLEGAL_MESSAGE» при `send()` означает, что Windows на кассе не умеет современный TLS. Это Windows XP и Windows 7 без обновлений.

- **Windows 7:** установить KB3140245 и включить TLS 1.2 для WinHTTP через реестр (`DefaultSecureProtocols = 0x800` в `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Internet Settings\WinHttp`, для 64-битной системы также в `Wow6432Node`). После перезагрузки заработает.
- **Windows XP:** TLS 1.2 недоступен. Варианты: обновить кассу; поставить рядом прокси (например, stunnel), который принимает HTTP от 1С и ходит на сервер по HTTPS; или в крайнем случае разрешить на сервере HTTP без редиректа — тогда токен идёт по сети открытым, и это допустимо только в закрытой сети аптеки.

## 6. Соответствие регистру «Бонусы» в 1С

Если бонусы раньше велись в регистре 1С, поля соотносятся так:

| 1С 7.7, регистр «Бонусы» | API |
|:--|:--|
| ШтрихКодДисконта | `short_code` |
| Сумма со знаком по флагу приход/расход | `amount` (плюс — начисление, минус — списание) |
| Отдел | `pharmacy_number` |
| ID документа | `document_number` (до 12 символов) |
| Остаток за текущий период | `GET /api/v1/bonus/balance/{short_code}` |

В API остаток дополнительно делится по юридическим лицам (`inn`); в регистре 1С этого нет. При переносе начальных остатков нужно решить, на какое юрлицо их записывать.
