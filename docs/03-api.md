# API — все адреса

Все адреса начинаются с:

```
http://ваш-сайт/api/v1
```

В каждом запросе нужно передавать токен:

```
Authorization: Bearer ВАШ_ТОКЕН
```

## 1. Проверка работы

**GET** `/api/v1/check`

Ответ:

```json
{"message": "API работает!"}
```

## 2. Карты клиентов

### Посмотреть карту

**GET** `/api/v1/bonus/card/{код_карты}`

Ответ — информация о карте.

### Создать карту

**POST** `/api/v1/bonus/card`

Нужно передать:
- `short_code` — код карты (от 9 до 13 символов)
- `firstname` — имя
- `name` — фамилия
- `birthdate` — дата рождения
- `gender` — пол (0 — мужской, 1 — женский)
- `newsletter_agree` — согласие на рассылку (0 или 1)
- `status` — статус (0 — активна, 1 — аннулирована, 2 — заменена)

Остальные поляoptional: отчество, email, телефон, город, guid.

### Изменить карту

**PUT** `/api/v1/bonus/card/{код_карты}`

Можно обновить любые поля.

### Удалить карту

**DELETE** `/api/v1/bonus/card/{код_карты}`

Карта помечается как удалённая.

### Посмотреть баланс

**GET** `/api/v1/bonus/balance/{код_карты}`

Ответ:

```json
{"balance": 150.50}
```

### Найти карту по телефону

**POST** `/api/v1/bonus/find`

Нужно передать `phone` в формате `+79001234567`.

## 3. Бонусные операции

### Начислить бонусы

**POST** `/api/v1/bonus/increase`

Нужно передать:
- `short_code` — код карты
- `pharmacy_number` — номер аптеки
- `inn` — ИНН организации
- `document_date` — дата документа
- `document_number` — номер документа
- `document_type` — тип документа
- `amount` — сумма (больше 0)

### Вернуть начисление

**POST** `/api/v1/bonus/increase/return`

Те же поля, но сумма отрицательная.

### Списать бонусы

**POST** `/api/v1/bonus/decrease`

Те же поля, что при начислении. Сумма вычитается.

### Вернуть списание

**POST** `/api/v1/bonus/decrease/return`

Сумма отрицательная.

### Отменить операцию

**POST** `/api/v1/bonus/increase/cancel`  
или  
**POST** `/api/v1/bonus/decrease/cancel`

Нужно передать код карты, номер документа, тип документа и дату.

### Перевести бонусы с карты на карту

**POST** `/api/v1/bonus/move`

Нужно передать:
- `short_code_from` — карта, с которой переводим
- `short_code_to` — карта, на которую переводим
- `document_date` — дата
- `document_number` — номер документа
- `document_type` — тип документа

Весь баланс переводится сразу.

## 4. Аптеки

### Список аптек

**GET** `/api/v1/bonus/pharmacy`

### Посмотреть аптеку

**GET** `/api/v1/bonus/pharmacy/{номер}`

### Создать аптеку

**POST** `/api/v1/bonus/pharmacy`

Нужно передать:
- `legal_entity` — ID юридического лица
- `number` — номер аптеки (от 1 до 99)
- `name` — название

### Изменить аптеку

**PUT** `/api/v1/bonus/pharmacy/{номер}`

### Сменить организацию у аптеки

**PUT** `/api/v1/bonus/pharmacy/legal-entity/{номер}`

Нужно передать `legal_entity` — новый ID организации.

### Удалить аптеку

**DELETE** `/api/v1/bonus/pharmacy/{номер}`

## 5. Юридические лица

### Список организаций

**GET** `/api/v1/bonus/legal-entity`

### Посмотреть организацию

**GET** `/api/v1/bonus/legal-entity/{ИНН}`

### Создать организацию

**POST** `/api/v1/bonus/legal-entity`

Нужно передать:
- `inn` — ИНН (от 10 до 20 цифр)
- `name` — название

### Изменить организацию

**PUT** `/api/v1/bonus/legal-entity/{ИНН}`

### Удалить организацию

**DELETE** `/api/v1/bonus/legal-entity/{ИНН}`

## Ответы сервера

| Код | Что означает |
|-----|--------------|
| 200 | Всё хорошо, данные получены или изменены |
| 201 | Что-то создано |
| 202 | Что-то не найдено или не получилось |
| 204 | Удалено успешно |
| 401 | Нет токена или он неправильный |
| 404 | Такого адреса нет |
| 422 | Данные не прошли проверку. В ответе написано, какие поля заполнены неверно |

Ошибки тоже приходят в формате JSON.
