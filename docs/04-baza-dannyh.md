# База данных

В проекте 5 основных таблиц.

## 1. cards — карты клиентов

| Поле | Что это |
|------|---------|
| short_code | Код карты |
| firstname | Имя |
| name | Фамилия |
| lastname | Отчество |
| birthdate | Дата рождения |
| email | Почта |
| phone | Телефон |
| city | Город |
| gender | Пол (0 — муж, 1 — жен) |
| newsletter_agree | Согласие на рассылку |
| guid | Внешний код |
| status | Статус (0 — активна, 1 — аннулирована, 2 — заменена) |

## 2. legal_entities — юридические лица

| Поле | Что это |
|------|---------|
| inn | ИНН |
| name | Название организации |

## 3. pharmacies — аптеки

| Поле | Что это |
|------|---------|
| number | Номер аптеки |
| name | Название |
| legal_entity_id | Ссылка на организацию |

## 4. card_operations — операции

| Поле | Что это |
|------|---------|
| card_id | Ссылка на карту |
| action | Тип действия (0 — начисление, 1 — списание, 2 — перевод, 3 — возврат начисления, 4 — возврат списания) |
| document_date | Дата документа |
| document_number | Номер документа |
| document_type | Тип документа |
| amount | Сумма |

## 5. bonus_balances — бонусные балансы

| Поле | Что это |
|------|---------|
| card_id | Ссылка на карту |
| legal_entity_id | Ссылка на организацию |
| sum | Сколько бонусов |

## Связи

- У одной карты много операций и балансов.
- У одной организации много аптек и операций.
- У одной аптеки много операций.
