# База данных

Полная схема со связями и служебными таблицами — в [docs/15](15-shema-bazy-dannyh.md).

В проекте 4 основные таблицы.

## 1. cards — карты клиентов

| Поле | Что это |
|------|---------|
| short_code | Код карты |
| firstname | Имя |
| name | Фамилия |
| lastname | Отчество |
| birthdate | Дата рождения |
| email | Почта |
| phone | Телефон |
| city | Город |
| gender | Пол (0 — муж, 1 — жен) |
| newsletter_agree | Согласие на рассылку |
| guid | Внешний код |
| status | Статус (0 — активна, 1 — аннулирована, 2 — заменена) |
| legal_entity_id | Организация-владелец карты (по первой операции) |

## 2. legal_entities — юридические лица

| Поле | Что это |
|------|---------|
| inn | ИНН |
| name | Название организации |

## 3. pharmacies — аптеки

| Поле | Что это |
|------|---------|
| number | Номер аптеки |
| name | Название |
| legal_entity_id | Ссылка на организацию |

## 4. card_operations — операции

| Поле | Что это |
|------|---------|
| card_id | Ссылка на карту |
| legal_entity_id | Ссылка на организацию |
| pharmacy_id | Ссылка на аптеку (пусто у переносов) |
| action | Тип действия (0 — начисление, 1 — списание, 2 — перевод, 3 — возврат начисления, 4 — возврат списания, 5 — отмена/сторно) |
| document_date | Дата документа (у отмены — день отмены) |
| document_number | Номер документа |
| document_type | Тип документа |
| amount | Сумма со знаком |
| wallet_after | Остаток кошелька (карта + организация) после этой операции |
| card_after | Остаток карты после этой операции. Баланс карты = `card_after` последней строки |
| parent_id | У отмены — ссылка на отменённую операцию |
| deleted_at | Заполнено — операция отменена (погашена сторно). Строка остаётся в цепочке остатков |

Отдельной таблицы остатков нет: журнал — единственный источник баланса.

## Связи

- У одной карты много операций.
- У одной организации много аптек и операций.
- У одной аптеки много операций.
