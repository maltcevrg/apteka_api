# О проекте

## Что делает программа

Это система бонусных карт для сети аптек. У клиента есть карта, на которой хранятся бонусы. Бонусы можно тратить и получать обратно.

## Главные сущности

| Что | Зачем нужно |
|-----|-------------|
| Карта клиента | У каждого клиента своя карта с номером |
| Юридическое лицо | Организация, которой принадлежит аптека |
| Аптека | Торговая точка, где можно потратить бонусы |
| Операция | Запись о том, сколько бонусов прибавили или вычли |
| Баланс | Сколько бонусов осталось на карте |

## Как работает

1. Клиент получает бонусную карту.
2. В аптеке ему начисляют бонусы за покупку.
3. Клиент может потратить бонусы на следующую покупку.
4. Если нужно, операцию можно отменить или вернуть бонусы.
5. Бонусы можно перевести с одной карты на другую.

## Технологии

- **Laravel** — основа сайта и API
- **MySQL** — база данных
- **Passport** — защита API через токены
- **Vue.js** — веб-интерфейс
