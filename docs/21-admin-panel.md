# Админ-панель

Адрес: `https://lek-torg.ru/admin`. Вход по **логину и паролю**. Работает на том же Laravel, без отдельных сборок и библиотек — обычные страницы, сессии в файлах, защита форм (CSRF).

## 1. Пользователи и роли

Пользователи хранятся в таблице `users`: `login`, `role`, `password` (хеш bcrypt; пока пароль не задан — `NULL`), `last_login_at`. Самостоятельной регистрации нет.

| Роль | Что может |
|---|---|
| **Администратор** (`admin`) | всё, включая создание пользователей, роли, сброс паролей |
| **Редактор** (`editor`) | аптеки, юрлица, загрузка из 1С, отчёты |
| **Пользователь** (`user`) | только просмотр справочников и отчёты |

**Первый администратор** создаётся без пароля: `https://lek-torg.ru/obnovlenie.php?key=СЕКРЕТ&admin=логин` (или `php artisan bonus:admin логин`). Остальных заводит администратор в разделе «Пользователи»: указывает логин, имя и роль — пароль **не задаётся**.

**Первый вход.** Человек открывает `/admin/login`, вводит только логин. Если пароль ещё не задан, система ведёт на страницу «Первый вход», где он придумывает пароль (дважды). Дальше вход — по логину и паролю. Пароль нигде не передаётся по ссылке и не хранится в открытом виде.

**Требования к паролю:** 8–64 символа, латинские буквы и цифры (обязательно и те, и другие), допустимы `! @ # $ % ^ * ( ) _ + - = . , : ; ? [ ] { } ~`. Без пробелов и кириллицы — так пароль не сломает ни адресную строку, ни конфиги.

**Забыл пароль** — администратор нажимает «Сбросить пароль» у пользователя: при следующем входе тот снова задаст пароль сам. Если пароль забыл единственный администратор — `obnovlenie.php?key=…&admin=его_логин` делает то же самое. Свой пароль любой пользователь меняет по ссылке на своём логине в шапке.

Защита: нельзя удалить себя и последнего администратора; нельзя снять роль администратора с последнего администратора; 10 неудачных попыток входа в минуту с одного адреса — блокировка.

## 2. Разделы

### Обзор
Количество юрлиц, аптек, карт, операций и последняя операция журнала.

### Аптеки
Таблица всех аптек с текущим ИНН. В строке — выпадающий список юрлиц и «Сохранить» (перевод на другое юрлицо) и кнопка «Удалить» (с подтверждением). Ниже — форма «Добавить аптеку» (номер 0–99, название, юрлицо); номер должен быть свободен. Удаление мягкое: чеки аптеки остаются в журнале, а номер можно использовать снова — при этом восстанавливается та же запись.

Смена ИНН влияет только на **новые** операции: уже записанные чеки хранят своё юрлицо и не меняются.

### Юрлица
Список с ИНН, названием, числом аптек и карт-владельцев. Форма добавления (ИНН 10–12 цифр + название), ИНН должен быть уникален. Удалить можно только юрлицо **без аптек** — сначала перевести их на другое юрлицо или удалить. Удаление мягкое: операции и карты остаются.

### Загрузка из 1С
Форма с файлами выгрузки 1С **как есть** — кодировка Windows-1251 или UTF-8, разделитель `;`, русские заголовки:

| Файл | Заголовки |
|---|---|
| `СправочникЮЛ.csv` | `ИНН;Наименование` (КПП после `\` отбрасывается) |
| `СправочникАптеки.csv` | `НомерАптеки;Наименование;ИНН` |
| `Бонусы<ИНН>.csv` (несколько) | `short_code;firstname;name;lastname;birthdate;phone;city;gender;newsletter_agree;status;guid;balance` |

ИНН для файлов карт берётся из имени файла; если его там нет — указывается в поле формы. Можно загружать любую часть набора (только карты, только справочники). Дата документа «Ввод остатков» задаётся в форме (по умолчанию сегодня).

Правила те же, что у команды `bonus:import` (общий код — `Services/ImportService.php`):
- юрлицо ищется по ИНН, аптека по номеру, карта по номеру карты; существующие обновляются;
- остаток карты становится первой операцией журнала (начисление от юрлица файла, тип «Ввод остатков»);
- картам, у которых уже есть операции, остаток повторно не вводится — повторная загрузка безопасна;
- всё в одной транзакции: ошибка в файле — ничего не записано.

После загрузки показывается результат: сколько юрлиц/аптек/карт обработано, сколько остатков введено, что пропущено и почему.

### Пользователи (только администратор)
Список: логин, имя, роль (меняется на месте), состояние («ждёт первого входа» / «активен»), последний вход, «Сбросить пароль», «Удалить». Форма создания: логин, имя, роль.

### Отчёты
Выбор периода: предустановленные (сегодня, вчера, неделя, текущий/прошлый месяц, текущий/прошлый квартал, год) или произвольные даты. Сами отчёты — по отдельному ТЗ ([docs/20](20-plan-otchetov.md)); страница готова принять их.

## 3. Устройство

| Что | Где |
|---|---|
| Маршруты `/admin/...` | `packages/Solt/Bonus/src/routes/admin.php` (группа `web`) |
| Контроллеры | `Http/Controllers/Admin/` — Auth (вход, первый вход, смена пароля), User, Dashboard, Pharmacy, LegalEntity, Import, Report |
| Проверка входа | `Http/Middleware/AdminAuth.php` — гость → `/admin/login`; `AdminRole.php` — роли (`admin.role:admin,editor`) |
| Страницы | `resources/views/admin/*.blade.php`, общий `layout.blade.php` (стили внутри, без сборки) |
| Модель пользователя | `app/Models/User.php` (роли, правила пароля); миграции `2026_12_04_000001_users_login.php`, `2026_12_05_000001_users_roles.php` |
| Команда | `Console/AdminUserCommand.php` — `bonus:admin` |
| Тесты | `Tests/Feature/Admin/AdminPanelTest.php`, `RolesTest.php` |

Выкладка на хостинг: файлы из `main` + `obnovlenie.php?key=…` (миграции, кэши), затем `…&admin=логин` и первый вход на `/admin/login`. Для сессий нужна запись в `storage/framework/sessions` (как и для кэшей — уже есть).
