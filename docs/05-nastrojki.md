# Настройки

Все настройки лежат в файле `.env` в папке с проектом.

## Основное

| Переменная | Что это | Пример |
|------------|---------|--------|
| APP_NAME | Название приложения | Laravel |
| APP_ENV | Среда работы | local |
| APP_DEBUG | Показывать ошибки | true |
| APP_URL | Адрес сайта | http://localhost |

## База данных

| Переменная | Что это |
|------------|---------|
| DB_CONNECTION | Тип базы (mysql) |
| DB_HOST | Адрес сервера базы |
| DB_PORT | Порт (обычно 3306) |
| DB_DATABASE | Имя базы данных |
| DB_USERNAME | Логин |
| DB_PASSWORD | Пароль |

## Почтa и очередь

| Переменная | Пример |
|------------|--------|
| MAIL_MAILER | smtp |
| MAIL_HOST | mailhog |
| MAIL_PORT | 1025 |
| QUEUE_CONNECTION | sync |

## Тесты

Для тестов используется отдельный файл `.env.testing`. В нём другая база данных.

Чтобы запустить тесты:

```bash
vendor/bin/phpunit
```

## Важно

Файл `.env` не загружается в репозиторий. Каждый создаёт его сам из `.env.example`.
