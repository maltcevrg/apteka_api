# Apteka API

Это бэкенд для бонусных карт в аптеках. С его помощью можно:

- заводить бонусные карты клиентов;
- смотреть баланс карты;
- начислять и списывать бонусы;
- отменять операции;
- переводить бонусы с одной карты на другую;
- управлять аптеками и юридическими лицами.

## Что внутри

- PHP 8 + Laravel 9
- База данных MySQL
- API защищено токенами (Laravel Passport)
- Есть веб-часть на Vue.js, но основное — API

## Быстрый старт

1. Скопируйте файлы проекта на сервер или компьютер.
2. Создайте файл `.env` из примера `.env.example`.
3. Укажите в `.env` подключение к базе данных.
4. Установите пакеты PHP:
   ```bash
   composer install
   ```
5. Создайте ключ приложения:
   ```bash
   php artisan key:generate
   ```
6. Создайте таблицы в базе:
   ```bash
   php artisan migrate
   ```
7. Запустите сервер:
   ```bash
   php artisan serve
   ```

API будет доступно по адресу `http://localhost:8000/api/v1`.
